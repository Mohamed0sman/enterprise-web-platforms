## ⚡ خيارات النشر على Vercel

### الخيار 1: نشر المستودع كاملاً (Monorepo)
* قم بربط هذا المستودع بحسابك على [Vercel](https://vercel.com).
* ستقوم Vercel بنشر كافة المواقع، حيث يتاح كل موقع عبر مساره الخاص:
  * `https://your-domain.vercel.app/site12-sahab-fintech/`
  * `https://your-domain.vercel.app/site10-mathaq-cloud-kitchens/`
  * `https://your-domain.vercel.app/site13-ruwwad-venture-capital/`
  * وهكذا لبقية المنصات.
* تم إعداد ملف `vercel.json` لتحويل الصفحة الرئيسية تلقائياً إلى منصة سحاب للتقنية المالية.

### الخيار 2: نشر أي موقع بشكل منفصل تماماً بنطاق مخصص
إذا أردت تخصيص دومين خاص لأي موقع (مثلاً: `sahab.yourdomain.com`):
1. في لوحة تحكم Vercel، اضغط **Add New Project** واختر نفس المستودع.
2. في إعداد **Root Directory**، اضغط **Edit** واختر مجلد الموقع (مثل: `site12-sahab-fintech`).
3. اضغط **Deploy**، وسيعمل الموقع كأنه مشروع مستقل تماماً بشاشته الكاملة بدون أي مسار فرعي.
